# Ícones de tipo de arquivo

Os ícones SVG usados em `docs/app.js` para representar tipos de arquivo
(PDF, Word, Excel, PowerPoint, ZIP, imagem, texto e genérico) são baseados
na biblioteca [Bootstrap Icons](https://icons.getbootstrap.com/), incorporados
localmente como SVG inline (sem dependência de CDN) para funcionar offline
no PWA.
